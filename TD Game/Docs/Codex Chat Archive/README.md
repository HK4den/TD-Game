# Codex chat archive

This folder contains portable, readable transcripts from Codex chats associated with the Wizliens / TD Game project. These files are Markdown archives, not live conversations; they cannot be reopened or resumed as Codex chats on another computer.

## Coverage and limits

The Codex app exposed four project-local Codex chats for this folder on October 2, 2026. I paged through all available history for each chat. The export chat has two turns; the game-context chat has seven; the landing-sound chat has 20; and the project-renaming chat has 108. The landing-sound and project-renaming histories required multiple pages. The archive chat was still active while captured, so its last turn reflects the export request in progress.

The export includes user and assistant messages only. It omits tool logs, command outputs, internal reasoning, and local computer paths. Unrelated personal/general ChatGPT conversations were not included. Some unusually long individual messages may be shortened by the app's message-length limit.

## Files

- `TRANSCRIPT-*.md`: available user and assistant messages from each listed project-local Codex chat.
- `PROJECT-NOTES-INDEX.md`: index of existing project handoff, design, setup, and review documents in the repository.

## On another computer

Clone the repository and open these Markdown files in any editor. To work with the project in Codex, open the cloned folder as a project and read `Wizliens Game Handoff.txt` for design and implementation context. The transcript files are references, not importable chat sessions.

Before pushing to GitHub, review these documents for material you do not want included in that repository. Repository visibility and collaborators determine who can read committed files.
